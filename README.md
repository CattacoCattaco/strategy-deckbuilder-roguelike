# Mutant Machines
This is a deckbuilder roguelike where you modify your cards to improve their effects. Each card has a range (left number) and an effect size (right number). Each card also has five modifier slots. There are two types of modifiers: Effect modifiers and modifier modifiers. Effect modifiers add an effect to the card (Ex: damage, heal, or move) while modifier modifiers change the way that effect modifiers work (Ex: repeating them, allowing them to jump over barriers). As you progress through the different floors, encounters will get harder. Survive as long as you can.

## Controls
Map:
* WASD to move
* E to enter level
Level:
* Click on a card to play it. For each effect, there will be markers of that color on every tile you could target with the effect. Click the tile to target it.
